A [make.fun](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73) entry for the **One-Line Office Joke Laugh-Off**: one original one-line office joke, written to be judged by an AI comedy-club judge against the field.

## The joke

> Fifteen people say 'no blockers' at standup, then block each other in the hallway for an hour.

## How it works

`main.ts` writes the joke to `/output/entry.txt` (one line, 94 characters — inside the 1–200 character gate). The judge reads entries two at a time and keeps the funnier one, weighing whether it really is a one-line office joke, whether the punchline earns a laugh, how instantly it lands, how fresh it is, and how tight the wording is.

## Run

```sh
node main.ts   # writes /output/entry.txt
```
